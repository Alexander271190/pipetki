Баг №3: calcStatus — неактивные просроченные
Функция calcStatus:

javascript
function calcStatus(p) {
  if (!p.active) return 'inactive';       // ← приоритет: неактивные первыми
  // ... проверка просрочки ...
}
Если у пипетки active = false и просроченная поверка — она покажет «Неактивна», а не «Просрочена».

Это было замечание ранее — вы хотели, чтобы просрочка показывалась даже у неактивных. Если так — нужно поменять порядок:

javascript
function calcStatus(p) {
  // Сначала проверяем просрочку
  if (p.last_calibration && p.interval) {
    const last = new Date(p.last_calibration);
    const next = new Date(last);
    next.setMonth(next.getMonth() + p.interval);
    const now = new Date(); now.setHours(0,0,0,0);
    const dl = Math.ceil((next - now) / 86400000);
    if (dl < 0) return 'danger';
  }
  if (!p.active) return 'inactive';
  // ...
}
Решение: если хотите — замените calcStatus на версию с приоритетом просрочки.

Я редактировал

function calcStatus(p) {
  if (!p.active) return 'inactive';
  if (!p.last_calibration || !p.interval) return 'danger';
  const last = new Date(p.last_calibration);
  const next = new Date(last);
  next.setMonth(next.getMonth() + p.interval);
  const now = new Date(); now.setHours(0,0,0,0);
  const daysLeft = Math.ceil((next - now) / 86400000);
  if (daysLeft < 0) return 'danger';
  if (!p.active) return 'inactive';
  if (daysLeft <= settings.warnDays) return 'warn';
  return 'ok';
}





Баг №4: Двойной showToast при истечении сессии
При истечении токена apiRequest ловит 401:

javascript
if (response.status === 401) {
  clearSession();
  renderAuthUI();
  showToast('Сессия истекла, войдите заново', 'error');   // ← Toast 1
  throw new Error('Неавторизован');
}
Тот, кто вызвал apiRequest (например, loadPipetteData), тоже показывает toast:

javascript
catch (error) {
  showToast('Ошибка загрузки данных', 'error');   // ← Toast 2
}
Последствие: два подряд сообщения.

Как исправить: в loadPipetteData и подобных не показывать toast, если ошибка 'Неавторизован':

javascript
catch (error) {
  if (error.message !== 'Неавторизован') {
    showToast('Ошибка загрузки данных', 'error');
  }
}
Не критично, но улучшает UX.
