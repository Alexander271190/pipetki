# 🔬 Система учёта пипеток и их поверок

**КГБУЗ Краевая клиническая больница КДЛ**

Веб-приложение для учёта лабораторных пипеток, контроля сроков поверки и ведения журнала калибровок.

---

## 📋 Возможности

- 🔐 **Авторизация** с ролями: администратор, старший лаборант, пользователь
- 📊 **Реестр пипеток** с поиском, фильтрацией и сортировкой
- 📅 **Автоматический расчёт** следующей даты поверки и статуса (в норме / скоро / просрочено)
- 📖 **История поверок** с свидетельствами, организациями и примечаниями
- 📤 **Экспорт в CSV/Excel** pdf с учётом фильтров
- 🔔 **Напоминания** о приближающихся и просроченных поверках
- 📱 **Адаптивный интерфейс** — работает на телефонах и планшетах
- 👥 **Разграничение прав**: обычный пользователь видит только свой отдел
- 📝 **Журнал действий** (аудит) для администратора

---

**Всё в одном контейнере** — фронтенд, бэкенд и база данных.

---

## 🛠️ Технологии

| Компонент | Технология |
|-----------|-----------|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |
| **Backend** | Node.js 18, Express.js |
| **База данных** | SQLite (better-sqlite3) |
| **Авторизация** | JWT (jsonwebtoken) |
| **Контейнеризация** | Docker, Docker Compose |
